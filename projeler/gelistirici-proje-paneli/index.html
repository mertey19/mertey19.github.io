Geliştirici Proje Paneli

Yazılım fikirlerini, todo'ları ve GitHub projelerini tek panelden yöneten geliştirici odaklı dashboard.

01Genel Bakış

DevProject Manager, geliştiricinin kendi işlerini yönetmesi için tasarlanmış bir kontrol paneli. Yazılım fikirleri, GitHub bağlantıları, yapılacaklar listesi, README hazırlık durumu, teknoloji yığınları, kütüphane notları ve Markdown dışa aktarımı tek yerde toplanıyor.

Uygulama hem web hem masaüstü olarak çalışıyor: Next.js tabanlı arayüz Electron ile paketlenip Windows uygulamasına dönüştürülebiliyor. Veri katmanı Supabase üzerinde; tablolar, indeksler, tetikleyiciler ve satır düzeyi güvenlik (RLS) politikaları migration dosyasında tanımlı.

02Öne Çıkan Özellikler

  • Fikir ve proje takibi — yazılım fikirlerini GitHub bağlantılarıyla birlikte kaydetme
  • Yapılacaklar — proje bazlı todo listeleri ve ilerleme durumu
  • README hazırlık durumu — hangi projenin dokümantasyonunun eksik olduğunu görme
  • Teknoloji ve kütüphane notları — yığın bilgisi ve kullanılan kütüphaneler üzerine notlar
  • Markdown dışa aktarma — panel içeriğini paylaşılabilir Markdown'a çevirme
  • Masaüstü paketi — Electron ile Windows uygulaması derleme

03Teknik Notlar

  • Supabase migration'ı yalnızca tabloları değil; indeksleri, tetikleyicileri ve RLS politikalarını da içeriyor — veritabanı sıfırdan tek komutla kurulabiliyor.
  • Derleme çıktıları (.next, dist-desktop, dist-electron) bilinçli olarak depoya alınmıyor.
