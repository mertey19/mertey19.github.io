Akıllı Dosya Düzenleyici (Java)

Karışık klasörleri kategorilere ayıran, önizleme ve geri alma destekli güvenli masaüstü düzenleyici.

Java 17SwingMavenJackson
GitHub deposu← Tüm projeler

01Genel Bakış

Akıllı Dosya Düzenleyici'nin Java sürümü, karışık bir klasörü kategorilere ayıran bir masaüstü aracı. Görseller, videolar, PDF'ler, belgeler, arşivler, kod dosyaları, ses, kurulum dosyaları, tablolar ve sunumlar ayrı ayrı sınıflandırılıyor.

Uygulamanın temel ilkesi güvenlik: hiçbir dosya silinmiyor, hiçbir dosyanın üzerine sessizce yazılmıyor. Toplu taşımadan önce bir önizleme tablosu gösteriliyor ve her işlem JSON geçmişinden geri alınabiliyor.

02Öne Çıkan Özellikler

  • Kategori sınıflandırma — 11 dosya kategorisine göre otomatik ayırma
  • Önizleme tablosu — taşımadan önce dosya, mevcut yol, hedef ve kategori listesi
  • Çakışma güvenliği — aynı ada sahip dosyalar dosya (1).uzantı olarak yeniden adlandırılıyor
  • Geri alma — son işlemi data/history.json üzerinden geri alma
  • Özel kurallar — kendi uzantı → kategori eşlemelerinizi tanımlama
  • Otomatik düzenleme — WatchService ile yeni gelen dosyaları izleme

03Teknik Notlar

  • Java 17, Swing ve java.nio.file üzerine kuruldu; yapılandırma ve geçmiş Jackson ile JSON olarak saklanıyor.
  • JUnit 5 testleri sınıflandırma ve çakışma kurallarını kapsıyor — "silme yok, sessiz üzerine yazma yok" ilkesi testle korunuyor.
