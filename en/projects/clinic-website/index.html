Clinic Website

Modern clinic website built with Next.js 15 that stays up even when the database is unreachable.

Next.js 15React 19Tailwind CSSPrisma
GitHub repository← All projects

01Overview

Clinic Website is a public-facing site for a health clinic: home, about, services, service detail pages, contact and a sitemap. It is built with Next.js 15, React 19, TypeScript, Tailwind CSS and Prisma.

Its most notable trait is resilience: even when the database is unreachable, the public pages still render from fallback content. For a marketing site the worst outcome is a blank page, and this design prevents it.

02Key Features

  • Public pages — home, about, services and service details
  • Fallback content — pages still render when the database is unavailable
  • Contact page — clinic information and contact channels
  • Sitemap — generated for search engines
  • Prisma data layer — a schema-driven content model with automatic client generation

03Engineering Notes

  • The scope was deliberately narrowed — blog, FAQ, testimonials, appointments, admin dashboard and public form endpoints were all removed, reducing both attack surface and maintenance load.
  • Environment secrets stay out of the repository, and a postinstall step generates the Prisma client automatically.
