Warranty & Receipt Tracker

Tracker that gathers your purchases, warranty periods, and receipts in a single offline desktop app.

Java 21JavaFXSQLitePDFBox
GitHub repository← All projects

01Overview

Warranty & Receipt Tracker keeps your purchases, warranty periods and receipts in a single desktop application. What you bought, when the warranty expires and where the receipt lives are all in one place.

Warranty status is computed automatically: Active, Expiring Soon and Expired badges are assigned against a configurable threshold. The dashboard surfaces upcoming expirations, with an optional startup reminder.

02Key Features

  • Product management — name, brand, model, serial, category, store, purchase date, warranty, price, notes, receipts and images
  • Warranty status — automatic Active / Expiring Soon / Expired badges against a configurable threshold
  • Dashboard — overview cards, category breakdown, recently added products and upcoming expirations
  • Search and filter — by name, brand, model or serial; filter by category and status
  • File handling — safe copies of receipts and images with automatic duplicate renaming
  • Export — CSV via OpenCSV and PDF reports with summary statistics via PDFBox

03Engineering Notes

  • A layered architecture on Java 21 and JavaFX, with operational logging through SLF4J + Logback.
  • Attachments are stored as copies, so a record stays intact even if the original file is moved or deleted.
