Smart File Organizer (Java)

Safe desktop organizer that sorts messy folders into categories, with preview and undo support.

Java 17SwingMavenJackson
GitHub repository← All projects

01Overview

The Java edition of Smart File Organizer is a desktop tool that sorts a messy folder into categories: images, videos, PDFs, documents, archives, code, audio, installers, spreadsheets and presentations.

Safety is the guiding principle: nothing is deleted and nothing is silently overwritten. A preview table is shown before any bulk move, and every operation can be undone from a JSON history.

02Key Features

  • Category classification — automatic sorting into 11 file categories
  • Preview table — file, current path, target and category listed before any move
  • Collision safety — same-named files are renamed to file (1).ext
  • Undo — revert the last operation from data/history.json
  • Custom rules — define your own extension → category mappings
  • Auto-organise — watch for incoming files with WatchService

03Engineering Notes

  • Built on Java 17, Swing and java.nio.file, with configuration and history stored as JSON via Jackson.
  • JUnit 5 tests cover classification and collision rules, so the "no deletes, no silent overwrite" principle is enforced by tests.
