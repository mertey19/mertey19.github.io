# Portfolio icon provenance

The selected icon is an editorial `M.` monogram designed to match the portfolio's serif typography and existing orange accent.

- Generation route: built-in Codex ImageGen
- Use case: `logo-brand`
- Selection: editorial monogram direction
- Deterministic finishing: source artwork was cropped, flattened to the site's exact three-color palette, centered, and exported to the sizes listed in `manifest.json`

Final generation prompt:

> Create a bold editorial serif letter “M” monogram with one small orange period as a distinctive “M.” signature. Use a flat warm ivory `#faf9f6` square, near-black `#171410` for the letter, and vivid orange `#e8500a` for the period. Keep the mark centered, high-contrast, crisp, and recognizable at 16×16 pixels. No gradients, shadows, 3D, border, mockup, extra symbols, or watermark.
